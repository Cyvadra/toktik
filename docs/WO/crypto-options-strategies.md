## BTC 均线偏离度牛市价差策略 (Bull Put Spread)

### 1. 策略逻辑核心

策略性质：顺势动能策略 

入场信号：当 P > 0.15 时，判断市场处于短期强力上涨趋势，执行卖出(sell put)。

核心指标计算 ：

均线 (maLine)：简单移动平均线 （n=120）。

波动基准 M = max(Highest(H, 120) - Lowest(C, 120),Highest(C, 120) - Lowest(L, 120))

即 max( (120bars最高High - 120bars最低Close), (120bars最高Close - 120bars最低Low) )
 

偏离度 ：P = {Close - ma}/M

 

### 2. 完整交易要素表

| 维度             | 具体执行参数                                             |
| -------------------- | ------------------------------------------------------------ |
| 执行周期       | 1 小时线 (1h) 。                                             |
| 开仓条件       | P > 0.15                                                     |
| 卖出腿 (看涨，卖Put) | Put：行权价，到期日距离15天最近的期权里面选，delta在-0.5到-0.4之间选择，且权利金N（期权价格，取bid）>= 0.025 |
| 买入腿 (保险，买Put)  | 虚值 Put：到期日同卖出腿，delta在-0.15到-0.1之间选择 |
| 平仓      | 持有的sell put的期权（卖出腿）浮盈超过88%，先平仓(buy to flat)卖出腿；从平仓时开始算，对于买入腿，在24小时后自动平仓、或期间出现浮盈50%时立即平仓 |
| 持仓时间限制 | 最大持仓不超过48小时，否则自动全部平仓 |
| 仓位管理       | 单次开仓(1+1)张                           |

## BTC 均线偏离度熊市价差策略 (Bear Call Spread)

### 1. 策略逻辑核心

策略性质：逆势回撤或空头顺势策略 。

入场信号：当 P < -0.15 时，判断市场处于严重超跌或短期强下行趋势，执行看空卖出 。

核心指标计算：与牛市策略一致，仅信号方向相反 。

### 2. 完整交易要素表

| 维度             | 具体执行参数                                             |
| -------------------- | ------------------------------------------------------------ |
| 执行周期       | 1 小时线 (1h) 。                                             |
| 开仓条件       | P < -0.15                                                    |
| 卖出腿 (看空，卖Call) | Call：行权价，到期日距离15天最近的期权里面选，delta在0.4到0.5之间选择，且权利金N（价格，取bid）>= 0.025 |
| 买入腿 (保险，买Call)  | 虚值 Call：行权价 ，到期日同卖出腿，delta在0.1到0.15之间选择 |
| 平仓      | 持有的sell call的期权（卖出腿）浮盈超过88%，先平仓(buy to flat)卖出腿； 从平仓时刻开始，对于买入腿，在24小时后自动平仓，或期间出现浮盈50%时立即平仓 |
| 持仓时间限制 | 最大持仓不超过48小时，否则自动全部平仓 |
| 仓位管理       | 单次开(1+1)张              |

## 注意事项

- 期权交易，我们的策略会动态选择需要交易的期权。例如监控 BTC，则筛选以"BTC"作为 base_asset 的所有期权，再按到期日筛选（从now+15天开始，从后往前筛选），然后再按delta和价格筛选；筛选条件必须满足，否则放弃开仓机会；筛选后按盘口价差和成交量排序，选择需要交易的期权。

- 因此主程序和框架，需要支持期权筛选的功能。

- 如未筛选到符合条件的期权，继续向前搜索，但到期日必须在7天以上，否则放弃。

- 如果筛选条件能命中大于一个期权，根据盘口价差进行优选，选择 (ask-bid) / (ask+bid) 最小的那个； 价差相同情况下，选择成交量大的

- 波动基准 M 均线 偏离度，这些指标都以主要标的资产为准(underlying_price)，而非特定期权价格

- 相关浮盈浮亏等计算，以mark_close为准
