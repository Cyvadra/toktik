# 策略需求简报：期权趋势替代 (V2.0 精简版)

## 一、 核心运行环境
- **运行周期：** ≥ 8小时 (8h, 12h, 2d 等)。
- **初始标的：** 账户初始本金 100 BTC，交易 BTC 期权。

## 二、 信号触发 (Signal)
- **波动：** 最近 3 根 K 线内，至少有一根满足：`MA(Std,20)` 处在过去 120 根 K 线的 35% 分位以下。
- **突破入场：** 价格向上突破 `Max(唐奇安上轨20, 布林上轨20)`。

## 三、 统一执行动作 (Execution Standard)
> 无论是“首次开仓”、“加仓”还是“换仓”，执行逻辑完全一致：

- **选券：** `DTE ≈ 35` 天，且 `Delta ≈ 0.33` 的 Call。
- **定额：** 根据 IV 指数（100根K线分位）确定开仓系数 x：
  - `IV < 35%` → `x = 1.2`
  - `35% ≤ IV < 60%` → `x = 1.0`
  - `60% ≤ IV < 85%` → `x = 0.7`
  - *(注：120根K线的IV历史分位阈值：35, 60, 85)*
- **公式：** 单笔下单金额 = `x * 1 (BTC)`。

## 四、 持仓维护与逻辑重置 (Management)
- **加仓逻辑：** 价格每上涨 `0.75 * ATR(20)` 触发一次执行动作，最多加仓 2 次。
- **动态换仓 (Rolling)：**
  - 当单笔期权 `|Delta| > 0.55` 或 浮盈 > 66%：平仓该期权，并立即按“执行标准”重新开仓（维持风险敞口）。
- **归零重置 (软止损)：**
  - **监控：** 实时扫描持仓期权余额。
  - **判定：** 若单笔期权跌幅 ≥ 80%，程序逻辑上将其视为“已归零（持仓为0）”。
  - **效果：** 该仓位释放，当新的突破信号出现时，允许重新按照“首次开仓”逻辑入场。

## 五、 给 AI 开发的逻辑伪代码建议
```python
# 核心扫描逻辑
for position in current_positions:
    if position.pnl_percent <= -80%:
        mark_as_closed(position) # 逻辑归零，释放占用，允许新信号触发

if strategy_signal == "BREAKOUT" and active_slots < 3:
    execute_standard_order() # 调用统一的选券与定额逻辑

if position.delta > 0.55 or position.pnl_percent > 66%:
    close_position(position)
    execute_standard_order() # 止盈换仓
```

# 空头策略：期权趋势替代（空头 Put 版）

## 一、 核心运行环境
- **运行周期：** ≥ 8小时（8h, 12h, 2d 等）。
- **标的：** BTC 及其对应期权（购买 Put 替代空头合约）。

## 二、 信号触发 (Signal - Bearish)
- **波动：** 最近 3 根 K 线内，至少有一根满足：`Std/MA(Std)` 处在过去 120 根 K 线的 35% 分位以下。
- **突破入场（向下）：** 价格跌破 `Min(唐奇安下轨20, 布林下轨20) - 0.5 * ATR`。

## 三、 统一执行动作 (Put Execution)
> （开仓、加仓、换仓动作逻辑高度统一）

- **选券：** 选取距离到期日 `DTE ≈ 35` 天，且 `Delta ≈ -0.33` 左右的 Put（看跌期权）。
- **定额系数 x（IV 逆向调节）：**
  - `IV < 35%` → `x = 1.2`（波动率低，买入便宜）
  - `35% ≤ IV < 60%` → `x = 1.0`
  - `60% ≤ IV < 85%` → `x = 0.7`
  - `IV ≥ 85%` → `x = 0.5`（大跌时 IV 极高，需缩减开仓金额防止溢价过高）
- **公式：** 单笔下单金额 = `x * 1 (BTC)`。

## 四、 持仓维护与逻辑重置 (Management)
- **加仓逻辑：** 价格每下跌 `0.75 × ATR(20)` 触发一次执行动作，最多加仓 **1 次**。
- **动态换仓 (Rolling Down)：**
  - 当单笔 Put 的 `|Delta| > 0.55` 或 浮盈 > 66%：平仓当前 Put，并立即按“执行标准”重新开出新的 `Delta ≈ -0.33` 的 Put。
- **归零重置 (软止损)：**
  - **监控：** 实时扫描持仓 Put 余额。
  - **判定：** 若单笔 Put 跌幅 ≥ 80%（通常发生在行情反转大涨时），逻辑上视为“归零/持仓为 0”。
  - **效果：** 释放仓位槽位，等待下一个 8h/12h 级别的突破信号重新入场。

## 五、 给 AI 开发的逻辑差异点 (Dev Notes)
- **Delta 符号：** 注意 Put 的 Delta 是负数。在编写逻辑时，请务必使用绝对值 `|Delta|` 进行阈值判断（即从 `0.33` 增至 `0.55` 的监控）。
