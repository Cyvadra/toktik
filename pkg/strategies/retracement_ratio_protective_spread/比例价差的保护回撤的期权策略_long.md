# I 号升级：多头全周期伏击与趋势追击策略需求文档 (V6.0 Long)

指定在以下点位开仓，两组分开测试，通过环境变量指定信号级别（12h/1d）

信号已整理至同目录下 `12h_long.csv` 和 `1d_long.csv`

持仓期间遇到开仓信号时，重置仓位，平仓现有所有仓位，并重新开仓（进入一阶段）

当找不到符合条件的期权时，跳过开仓或组合建仓动作

## 一、第一阶段：低波三维共振伏击 (Ambush Phase)

### 1.1 入场条件与波动率引擎

- IV 过滤：DVOL < 最近12h DVOL 100根 95 分位。
- 合约期限：优选 70 天左右到期（硬性限制，自每次建仓时间的 55-85 天）。

### 1.2 比例价差构建

头寸分配：

- 卖出腿 ：卖出 1 份 Call，abs(delta)在0.5左右，记录期权费 $a 。开仓数量 n1 = 5 BTC / a。
- 买入腿 ：
  - 筛选 abs(delta) 最接近 0.3 的 2 个期权，按abs(delta)升序，分别记录期权费 $b $c
  - n2 = 5 BTC / (b+c) ; n2可以不等于n1
  - 买入腿 ：每个期权开仓数量 == n2 进行买入。

- 注释：预期买入腿1、2的行权价相邻，次要预期b+c约等于a，实现零成本或极低成本建仓。

### 1.3 止盈与决策机制（每个期权组合）

- 初步减仓：组合浮盈（当前买方和卖方的期权组合自开仓以来总盈利）>= 30% * 期权买方期初总支出(即0.3 * 5 BTC) 时，卖出腿平掉 1/3；买入腿全平，重新选券开仓。
- 策略转换：组合浮盈（当前买方和卖方的期权组合自开仓以来总盈利）>= 50% * 期权买方期初总支出(即0.5 * 5 BTC) 时，全部平仓，并立即切换为第二阶段（趋势追击模式）。

初步减仓后的操作：

- 平仓买入腿，再根据先前定义的买入腿筛选条件，重新选取期权，并按2/3的上次仓位，进行建仓

异常退出条件：

- 价格下跌超过 8 个 current ATR(14) 时，全部平仓离场。
- 20天 < 组合内任一期权到期日剩余天数 < 40 天，且underlying价格在开仓时underlying价格的 2 个 current ATR 内时，平仓并滚动至新 70 天期组合。   重新进入 1.1阶段

## 二、第二阶段：趋势破位追击 (Trend Following Phase)

### 2.1 入场触发

- 信号：阶段一 50% 盈利后全部平仓后，进入第二阶段。

### 2.2 账户与选券算法

- 资金占用：初始开仓净支出  （BuyPrice即买入腿的价格，SellPrice即卖出腿的价格）

- 卖出和买入腿期权的 Delta 强制限制条件：|Delta| 在 [0.05, 0.7] 之间。

$$
N \times (\text{BuyPrice} - \text{SellPrice}) = 2 \text{ BTC}
$$

- 买入腿 ：
  - 计算分位数时，取已完成的K线，不包含当前未完成Bar
  - A = 100根12h K线， std20 / ma(std20,20) 的 百分位数 （percentileRank）（即，当前 std20 / ma(std20,20) 相当于历史100根的 A 百分位，0-100）
  - B = 200根12h K线， DVOL 的 百分位数 
  - 记录行权价 KBuy
  - 按delta选取 Call 期权买入腿
  - 选取 DTE ∈ [25,40] 天，最接近 35 天的期权

$$
|\Delta_{L}| = \text{Clamp} \left( 0.2, 0.8, \left( \frac{2A + B}{300} \right) \right)
$$

- 卖出腿 ：

$$
K_{Sell} \ge K_{Buy} \times 115\%
$$

优选最接近边界的期权。

## 三、动态监控与风险控制（--interval运行级别）

### 3.1 换仓触发 (Rolling Up)

第二阶段，执行滚动的条件：

- 必要条件1：
  - 运行周期上，上一根12h bar为阴线，close < open

- 必要条件2（“或”的关系，任一满足）：
  - 盈利目标：(BuyPrice - SellPrice) 上涨 50%
  - Delta 激增：买入腿的 abs(Delta) 较开仓时增加 0.2

仓位滚动方法

- 平仓，然后按照 2.2 选券方法，重新选择期权组合开仓

### 3.2 资金递减管理

- 逻辑：每次触发换仓信号后，新开仓投入的总权利金 = 上一次投入总权利金 * 0.9
